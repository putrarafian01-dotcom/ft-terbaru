Letakkan file Excel bank soal (.xlsx atau .xlsm) di folder ini.
Format yang disarankan: baris pertama adalah header, dengan kolom Soal dan Jawaban.
Nama header alternatif yang dikenali: Pertanyaan/Question dan Answer/Kunci Jawaban.
Jika header tidak dikenali, aplikasi mencoba memakai kolom pertama sebagai soal dan kolom kedua sebagai jawaban.
Jangan letakkan file Excel berisi data rahasia yang tidak boleh diakses pengguna situs.
